# 完成第一次下载

**目标：** 在浏览器视频页面发现媒体、发起任务，并确认最终文件。尚未安装的用户先看带截图的[新电脑首次使用教程](first-run-on-new-machine.md)。

## 先播放网页中的视频

选择自己**有权保存**的普通 MP4 或未加 DRM 的 HLS 视频。打开原视频页面并点击播放，**不要关闭原标签页**。很多网站只有播放后才开始发出媒体请求。

打开 DownKit，确认顶部连接状态正常。若仍显示环境检测中或连接异常，先阅读[连接排查](../how-to/troubleshoot.md)。

## 选择完整的媒体资源

进入「资源嗅探」，找到「当前页面资源」中的检测结果：

| 地址特点 | 选择建议 |
| --- | --- |
| \`video.mp4\` | 通常可直接下载 |
| \`master.m3u8\` 或其他 \`.m3u8\` | HLS 播放清单，可能包含多个清晰度 |
| \`manifest.mpd\` | DASH 播放清单，可能包含独立音视频轨 |
| \`.ts\`、\`.m4s\` 或单独音轨 | 通常只是分片，不要误当完整视频 |

如果没有媒体，返回原网页重新播放或拖动进度条，再打开扩展。一个网页可能出现广告、多个清晰度或无关请求，请根据名称和 URL 选择。

## 提交一次下载任务

首次建议将「字幕」设为「不下载字幕」，避免语音模型的额外依赖。找到资源后点击一次「下载」。遇到播放列表时，要确认自己选择的是单个视频还是整个列表。

其他字幕模式可以尝试原站字幕；使用本地识别需要 whisper.cpp **和模型**，字幕翻译还需要 llama.cpp **和模型**。这些功能与界面语言设置互不影响。带 DRM 或鉴权失效的视频并不保证能下载。

## 确认任务与最终文件

进入「下载任务」查看进度。任务可能依次经过解析、下载、处理等阶段；**只有状态变为「已完成」才算成功**。可以使用界面提供的打开输出文件操作，或检查「设置 → 下载能力」配置的目录。

任务处于失败、暂停或处理中时，不要把它当成完整文件。先看错误信息，再按界面支持的操作重试或恢复。详细日志位于 \`Data/logs/\`，配置路径见[参考手册](../reference/configuration.md)。

成功后可用「打开工作台」切换到大屏 Web UI，也可以在「设置 → 界面与交互」切换弹窗/侧边栏。更多帮助：[故障排查](../how-to/troubleshoot.md) · [M3U8 示例](../examples/m3u8-download.md)。
