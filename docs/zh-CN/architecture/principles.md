# 架构原则

1. **优先复用成熟组件**：先调研 SDK、标准协议、开源库及现成工具，再考虑自研。
2. **单一下载核心**：Go Bridge 负责桌面下载状态和配置；浏览器多个入口共享功能与通信层。
3. **明确权限边界**：扩展管理 Cookie 与 Token；Web UI 只通过扩展中继操作。
4. **依赖可选、可替换**：FFmpeg、yt-dlp、whisper.cpp、llama.cpp 独立管理。
5. **配置优先**：核心保持简洁，变化点通过明确接口扩展。
6. **工程入口统一**：DEV2 管理构建、审查、文档与验证，根目录 AGENTS.md 是 Agent 契约。
