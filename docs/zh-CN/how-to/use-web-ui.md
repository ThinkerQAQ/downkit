# 使用 Web UI

先安装桌面 Bridge 并加载扩展，再在扩展顶部点击「打开工作台」。浏览器将打开 `http://127.0.0.1:17891/console/`。

Web UI 复用扩展的任务和设置能力；禁用扩展后，页面虽可加载但不能执行授权操作。修改扩展后需要到 `edge://extensions` 或 `chrome://extensions` 重新加载。

HTTP 服务仅监听本机回环地址，Token 不传给网页。

设置页参考 Android 的逐级导航：**设置 → 分类 → 组件详情 → 编辑配置**。界面语言与扩展打开方式位于 **设置 → 界面与交互**。工作台保留侧边图标导航；扩展弹窗与侧边栏使用紧凑图标导航。

扩展弹窗和 Side Panel 使用左侧图标导航，Web UI 使用完整侧栏。检测页将当前页面、下载选项与检测结果组织为独立分区。

## 查看运行日志

点击侧栏的「日志」查看 Bridge 与 Worker 记录，可搜索、按级别筛选、自动刷新、全选、复制或清空。侧栏入口可在「设置 → 界面与交互 → 显示日志入口」中关闭，日志文件仍保留在 `Data/logs/`。


## 查看版本号

在弹窗、侧边栏或 Web UI 中，打开「设置 → 关于」查看浏览器扩展版本和
正在运行的 Bridge 版本。顶部标题栏不再显示版本号。
