# First download

1. Install the desktop Bridge and unpacked extension.
2. Play media you have permission to save, then open **Detect** in DownKit.
3. Select the resource, subtitle mode and download target. For a playlist, choose one item or the entire list.
4. Use **Downloads** to monitor progress, retry, resume or locate the output.

Local transcription requires whisper.cpp and a model. Page-specific session media must be downloaded from the original browser page.
